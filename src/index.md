## Where to start

New to Bagisto? Read the [Introduction](./getting-started/introduction.md), learn your way around the [Admin Panel](./getting-started/admin-panel.md), then follow the [Store Setup Checklist](./getting-started/store-setup-checklist.md) from a fresh install to your first order.

## How this guide is organized

The guide follows the order you set up and run a store: **Getting Started**, **Generative AI**, **Theme**, **Store Setup**, **Configure**, **Catalog**, **Customers**, **Sales**, **Marketing**, **CMS** and **Reporting**, followed by the **extensions**.

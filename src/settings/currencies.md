# Currencies

Before launching your eCommerce website, you need to set up the currency in which you will be doing your business. The currency symbol will be visible in product prices, orders, invoices, transactions, etc. Here are the steps to add currency in Bagisto.

### Creating a currency

1. Go to **Settings >> Currencies**.

2. Click **Create Currency**, as shown in the image below.

   <ImagePopup src="/images/settings/create-currency.png" alt="Currency" />

3. Enter the following details:

   - **Code** – Code of the currency.

   - **Name** – Name of the currency.

   - **Symbol** – Symbol of the currency.

   - **Decimal** – Decimal value of the currency.

   - **Group Separator** – It helps to separate the currency by ",". For example: 2,50,000.

   - **Decimal Separator** – It helps to separate decimal values. For example, if you enter 3 decimal values, then the currency will be 200.000.

   - **Currency Position** – It helps to position the currency (left, right, etc.).

4. Click **Save Currency**.

   <ImagePopup src="/images/settings/save-currency.png" alt="Save Currency" />

5. The new **Currency** by the name of **Dirham** is listed, as shown below.

   <ImagePopup src="/images/settings/new-currency.png" alt="New Currency" />

### Enabling the currency on a channel

1. Go to **Settings >> Channels** and open the channel.

2. Under **Currencies and Locales**, select your new currency in the **Currencies** field.

3. Click **Save Channel**, as shown in the image below.

   <ImagePopup src="/images/settings/currency-channel.png" alt="Currency Channel" />

So, by following these steps, you can create a **Currency** in Bagisto.

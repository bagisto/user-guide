# Users

Admin users are the people who sign in to the admin panel. Each user has one role, which decides what they can see and do; create the role first under [Roles](./roles.md).

## Creating a user

1. Go to **Settings >> Users**.
2. Click **Create User**.

<ImagePopup src="/images/settings/user.png" alt="Users listing with the Create User button" />

3. Enter the user's **Name** and **Email**.
4. Enter the **Password** and confirm it.
5. Choose the **Role**.
6. Optionally upload an **Image** for the user's avatar.
7. Click **Save User**.

<ImagePopup src="/images/settings/create-user.png" alt="Create user form" />

The new user appears in the list and can sign in straight away with the email and password you set.

<ImagePopup src="/images/settings/user-output.png" alt="Users listing with the new user" />

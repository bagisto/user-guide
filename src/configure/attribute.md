# Attribute

Product attributes of the **Image** and **File** types let you upload files on the product form. The **Attribute** section sets the largest size those uploads can have.

1. Go to **Configure >> Catalog >> Products**.
2. In **Attribute**, enter the **Allowed Image Upload Size (in Kb)**.
3. Enter the **Allowed File Upload Size (in Kb)**.
4. Click **Save Configuration**.

<ImagePopup src="/images/configure/products-attribute.png" alt="Attribute section of the Products screen with the upload size limits" />

Enter the sizes in kilobytes, so `2048` allows files of up to 2 MB. The attribute types are described in [Attribute Input Types](../attribute/attribute-input.md).

# Attribute

Product attributes of the **Image** and **File** types let you upload a file on the product form. The **Attribute** section sets the largest size those uploads can have.

1. Go to **Configure >> Catalog >> Products**.
2. In **Attribute**, enter the **Allowed Image Upload Size (in Kb)**.
3. Enter the **Allowed File Upload Size (in Kb)**.
4. Click **Save Configuration**.

<ImagePopup src="/images/configure/products-attribute.png" alt="Attribute section of the Products screen with the upload size limits" />

Enter the sizes in kilobytes, so `2048` allows files of up to 2 MB. When no size has been saved, the limit is `2048`. **Allowed File Upload Size (in Kb)** also limits the [videos you upload to a product](../product-types/products.md#videos). These settings apply to the whole store.

The attribute types are described in [Attribute Input Type](../attribute/attribute-input.md).

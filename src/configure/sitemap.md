# Sitemap

A sitemap lists your storefront's pages so search engines can find and index them. The **Sitemap** screen decides whether sitemaps are generated for a channel and how many links each sitemap file holds. The sitemaps themselves are created under **Marketing >> Search & SEO >> Sitemaps**; see [Sitemaps](../marketing/sitemaps.md).

## Set up sitemap generation

1. Go to **Configure >> General >> Sitemap**.
2. In **Settings**, check that **Enabled** is switched on. It is on by default.
3. In **File Limits**, enter the **Maximum no. of URLs per file**. The default is `50000`.
4. Click **Save Configuration**.

<ImagePopup src="/images/configure/sitemap-settings.png" alt="Sitemap screen with the Settings and File Limits sections" />

Both settings are set per channel.

**Enabled:** When it is off, no sitemap files are generated for the channel, even for the sitemaps listed under **Marketing >> Search & SEO >> Sitemaps**.

**Maximum no. of URLs per file:** The largest number of links written to one sitemap file. When a channel has more pages than that, the links are split across several files. Search engines accept up to 50,000 links in one file, so don't set it higher.

# Create Attribute Family

Attribute Families allow you to import all the required product information in a single step. 

They are essentially a collection of attributes related to a specific product type.

In this tutorial, we’ll guide you on how to create attribute families in Bagisto.

## Create Attribute Family in Bagisto

1. Go to **Catalog >> Attribute Families**.

2. Click **Create Attribute Family**.

   <ImagePopup src="/images/attribute/create-family.png" alt="Attribute Family" />

3. Enter the attribute family **Code** and **Name**, as shown below.

   <ImagePopup src="/images/attribute/save-family.png" alt="Save Family" />

4. Click **Save Attribute Family**. The new attribute family is created and displayed in the grid.

   <ImagePopup src="/images/attribute/family-grid.png" alt="Family Grid" />

### Assigning attributes to the family

After the attribute family is created, you can edit it from the **Action** column of the grid.

- Drag the attributes you need from **Unassigned Attributes** into the family's groups.
- During the product creation process, you’ll now see this new attribute family available.

All assigned attributes are then visible on the product page for products belonging to this attribute family.

<ImagePopup src="/images/attribute/output.png" alt="Output" />

By following these steps, you can create and manage **Attribute Families** in Bagisto.

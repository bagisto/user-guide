# How to Create Categories in Bagisto

The category is a structure of your catalog. By creating a category, customers can find the specific product amongst the lot on your e-commerce website. It is used for making the hierarchical arrangement of your website. Here we have listed down steps to create a new category and root category in Bagisto.

### Root Category

Bagisto comes with a default root category, i.e., Root, but you can also create your own root category. The Root Category is not visible on the front end because it acts as a container to contain the categories to be displayed on the website.

### Steps to Create a New Root Category in Bagisto

1. Go to **Catalog >> Categories**.

2. Click **Create Category**, as shown in the image below.

   <ImagePopup src="/images/category/create.png" alt="Create Category in Bagisto" />

3. Under **General**, enter the **Name**, **Position** and **Description**, and add the category images.

4. Pick where the category sits under **Parent Category**.

5. Choose the **Display Mode**. Display mode is about which content detail is visible on the category page. There are three options:

   - **Products and Description:** Both the products and the description of the category are visible on the front end.

   - **Description Only:** Only the category description is visible on the front end.

   - **Products Only:** Only the products are visible on the front end.

   <ImagePopup src="/images/category/edit-category.png" alt="Edit Category Settings" />

6. Click **Save Category**. A new category is created by the name of **Electronic Items** as shown in the image below.

   <ImagePopup src="/images/category/category-grid.png" alt="Category Grid in Bagisto" />

7. Open the product edit page while creating a product, and you will be able to see the newly created category there.

   <ImagePopup src="/images/category/product-page.png" alt="Product Page Category Selection" />

### Category on Front-End

By following the above steps, you can create a new category.

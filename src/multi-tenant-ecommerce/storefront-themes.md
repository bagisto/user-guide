# Storefront Themes

A tenant's storefront can wear a different look depending on their subscription. Every store starts on the **Default** theme, and higher plans unlock a set of **premium themes** — distinct, ready-made designs a merchant can switch to without any code.

The premium designs are:

- **Breeze**
- **Fashion**
- **Commercia**
- **Adornments**

## Which themes a tenant can use

Premium themes are a plan allowance, set on each subscription plan as **Premium Themes: Included** or **Not included** (see [Subscription Plans & Billing](./subscription)). A tenant can compare what each plan includes on the **Billing >> Plans** screen, where **Premium Themes** is listed among the features.

- On a plan **without** premium themes, only the **Default** theme is available.
- On a plan **with** premium themes, all four premium designs become selectable.

## Choose a theme

A merchant sets the storefront theme on the channel. In the Tenant Admin panel, go to **Settings >> Channels**, open the channel, and under **Design** pick the **Theme** from the dropdown.

<ImagePopup src="/images/multi-tenant-ecommerce/tenant-theme-channel.png" alt="Channel theme selection" />

Only the themes the current plan allows appear as choices. Click **Save Channel** to apply the design to the storefront.

## Customize a theme

Once a theme is chosen, its content blocks — sliders, featured collections, static columns, footer links, and more — are managed under **Settings >> Themes**. Each row is a block belonging to a channel and theme, with its type, sort order, and status.

<ImagePopup src="/images/multi-tenant-ecommerce/tenant-theme-customization.png" alt="Theme customization blocks" />

Use **Create Theme** to add a block, the **Edit** icon to change one, and the sort order to control where it appears on the storefront.

## Downgrading removes premium themes

If a tenant moves to a plan that does not include premium themes, any channel still using a premium design is switched back to the **Default** theme automatically, and the merchant is emailed to let them know.

Their theme customizations are not lost — they are kept, and restored the moment the tenant upgrades again to a plan that includes premium themes.
